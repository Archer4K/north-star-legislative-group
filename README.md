# North Star Legislative Group

Next.js + Tailwind website for North Star Legislative Group.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React

## Replace before launch
- Team names and bios
- Official NSLG email
- Social URLs
- Real research publications
- Additional legislative initiatives
- Partner organizations/logos
- Contact form backend

## Deploy
Recommended flow:
1. Import this GitHub repository into Vercel.
2. Add your custom domain.
3. Configure the contact-form backend/environment variables.
